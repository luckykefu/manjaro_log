# KDE 配置开发文档

## 项目结构

```
kde_cfg_sh/
├── theme.sh       — 安装并应用 WhiteSur 主题/图标/光标
├── general.sh     — 通用配置 (字体/输入/KWin/KRunner/锁屏/活动)
├── WhiteSur-kde/          # 克隆自 vinceliuice/WhiteSur-kde
├── WhiteSur-icon-theme/   # 克隆自 vinceliuice/WhiteSur-icon-theme
├── WhiteSur-cursors/      # 克隆自 vinceliuice/WhiteSur-cursors
└── 开发文档.md
```

各脚本独立自包含，无相互依赖。

---

## theme.sh

安装并应用 WhiteSur Mac 风格主题。

### 配置

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `THEME_PROXY` | `socks5://127.0.0.1:1080` | 克隆代理 |

### 流程

```
for entry in WhiteSur-kde WhiteSur-icon-theme WhiteSur-cursors:
  ├─ installed()?
  │    ├─ 是 → 切换主题/光标
  │    └─ 否 → clone → install → 切换主题/光标
```

### 检测方式

| 组件 | 检测命令 |
|------|----------|
| WhiteSur-kde | `lookandfeeltool -l \| grep WhiteSur` |
| WhiteSur-icon-theme | `index.theme` 是否存在 |
| WhiteSur-cursors | `plasma-apply-cursortheme --list-themes` |

### 应用方式

| 组件 | 应用命令 |
|------|----------|
| WhiteSur-kde | `lookandfeeltool -a <name> --resetLayout` |
| WhiteSur-cursors | `plasma-apply-cursortheme WhiteSur-cursors` |

## general.sh

通用 KDE 系统配置。

### 配置项

```
config_kde_general
  ├─ config_fonts         → 思源黑体 (常规/标题/菜单/工具栏/等宽)
  ├─ config_input         → 鼠标加速 + NumLock 关闭
  ├─ config_kwin          → 热角/窗口特效/TabBox
  ├─ config_screenlocker  → 禁用自动锁屏和密码
  ├─ config_activities    → 活动历史保留 1 天
  └─ config_krunner       → 浮动模式
```

操作 `~/.config/` 下的 `kdeglobals`、`kcminputrc`、`kwinrc`、`kscreenlockerrc`、`kactivitymanagerd-pluginsrc`、`krunnerrc`。

## 开发指南

### 添加新脚本

1. 创建 `your_module.sh`
2. 首行 `cd "$(dirname "${BASH_SOURCE[0]}")"` 固定脚本目录
3. 入口函数底部加自执行判断:
   ```bash
   [[ "${BASH_SOURCE[0]}" == "$0" ]] && your_main_function
   ```
4. 在 `开发文档.md` 添加说明

### 调试

```bash
# 单独运行
./theme.sh
./general.sh
```
