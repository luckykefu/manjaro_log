## main.sh

双向密钥认证配置 + SSH 反向隧道管理。

### 用法

```bash
./main.sh --ip <远程IP> [选项]
```

| 选项 | 默认值 | 说明 |
|------|--------|------|
| `--ip IP` | (必填) | 远程服务器 IP |
| `--key PATH` | `~/.ssh/id_ed25519` | 本地密钥路径 |
| `--port N` | `2223` | 远程端口 |
| `--setup` | — | 仅配置密钥互信 |
| `--start` | — | 仅启动隧道 |
| `--stop` | — | 停止隧道 |
| `--status` | — | 查看状态 |

默认(无action): setup + start

### 处理逻辑

```
setup:
  本地有密钥? → 生成 ed25519
  清理旧 host key
  ssh-copy-id 推送公钥到远程
  远程生成密钥(如无)
  拉取远程公钥 → 追加到本地 authorized_keys

start:
  ssh -N -R <port>:localhost:22 root@<ip> (后台)

stop:
  kill PID → 删除 PID 文件

status:
  检查 PID 文件 + 进程存活
```

### 调试

```bash
# 状态
./main.sh --status

# 停止
./main.sh --stop

# 手动测试隧道
ssh -p 2223 lkf@localhost
```
