# mihomo 开发文档

## 项目结构

```
mihomo_sh/
├── main.sh       — 一站式配置脚本
└── 开发文档.md
```

## main.sh

安装 mihomo → 生成配置 → 启动 → 连通性检测，全自动。

### 用法

```bash
./main.sh --subscribe <订阅链接> [选项]
```

| 选项 | 默认值 | 说明 |
|------|--------|------|
| `--subscribe URL` | (必填) | 订阅链接 |
| `--output DIR` | `~/.config/mihomo` | 配置输出目录 |
| `--nameserver IP` | `223.5.5.5` | DNS 地址 |

### 处理逻辑

```
sudo pacman -S mihomo
  ↓
写入 config.yaml (proxy-providers type: http)
  ↓
nohup mihomo -d (mihomo 自动拉取订阅)
  ↓
curl gstatic → 检测连通性
```

### 配置原理

利用 mihomo 内置的 `proxy-providers.type: http`，在 config.yaml 中直接写入订阅 URL。mihomo 启动时自动下载并解析订阅，无需手动处理 base64 解码和协议解析。

```yaml
proxy-providers:
  my_sub:
    type: http
    url: <订阅链接>
    interval: 86400
```

### 调试

```bash
# 查看日志
tail -f /tmp/mihomo.log

# 检查端口
ss -tlnp | grep 7897

# 手动测试连通性
curl -x http://127.0.0.1:7897 http://www.gstatic.com/generate_204

# 重启
pkill mihomo && ./main.sh --subscribe <URL>

# 查看当前代理节点
curl -s http://127.0.0.1:9097/proxies/proxy | python3 -m json.tool
```
