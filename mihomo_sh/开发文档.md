# mihomo 开发文档

## 项目结构

```
mihomo_sh/
├── config.yaml    — 订阅配置（自动生成）
├── deploy.sh      — 安装 + 下载订阅
├── main.sh        — 一站式配置脚本
├── start.sh       — 启动 + 连通性检测
└── 开发文档.md
```

## main.sh

安装 mihomo → 预下载订阅 → 启动 → 连通性检测，全自动。

### 用法

```bash
./main.sh --subscribe <订阅链接>
```

| 选项 | 说明 |
|------|------|
| `--subscribe URL` | (必填) 订阅链接 |

### 处理逻辑

```
sudo pacman -S mihomo
  ↓
curl -x socks5://127.0.0.1:1080 订阅 → config.yaml
  ↓
nohup mihomo -d $PWD
  ↓
curl -x http://127.0.0.1:$port gstatic → 检测连通性
```

### 配置原理

订阅 URL 返回的是完整 Clash YAML 配置（含 proxies、proxy-groups、rules、DNS），直接作为 mihomo 的 config.yaml 使用。通过已运行的 shadowsocks 代理（socks5://127.0.0.1:1080）下载，解决订阅 URL 被墙的问题。

> 后续更新订阅：再次运行 `./main.sh --subscribe <URL>` 即可覆盖。

### 调试

```bash
# 查看日志
tail -f /tmp/mihomo.log

# 手动测试连通性
curl -x http://127.0.0.1:7890 http://www.gstatic.com/generate_204

# 重启
pkill mihomo && ./main.sh --subscribe <URL>

# 查看当前代理节点
curl -s http://127.0.0.1:9090/proxies/proxy | python3 -m json.tool
```
