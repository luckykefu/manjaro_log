# mihomo

## 脚本说明

| 脚本              | 用途                                          | 用法                                                |
| ----------------- | --------------------------------------------- | --------------------------------------------------- |
| `start.sh`        | 启动mihomo代理                                | `start.sh --tun` (TUN模式) 或 `start.sh` (普通模式) |
| `get_cfg.sh`      | 从远程URL下载订阅配置                         | `get_cfg.sh <url>`                                  |
| `ss_to_mihomo.sh` | SS配置转mihomo格式 (位于shadowsocks-rust目录) | `proxy/shadowsocks-rust/ss_to_mihomo.sh <ip>`       |

## 命令

```bash
# 启动 (TUN模式，全局代理)
proxy/mihomo/start.sh --tun

# 启动 (普通模式，仅代理端口)
proxy/mihomo/start.sh

# 停止
proxy/mihomo/start.sh stop

# 查看状态
proxy/mihomo/start.sh status
```

## 配置信息

- 代理端口: `7890` (mixed)
- 控制面板: `127.0.0.1:9090`
- TUN模式: 全局代理，劫持DNS
- 配置文件: `config.yaml`
