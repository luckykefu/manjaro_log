# 新时代两性关系策略

目标:获得快乐

## 关于主动性:

| 主动     | 不主动         | 备注                       |
| -------- | -------------- | -------------------------- |
| 可能得吃 | 等着她说去开房 | 后者可能性几乎为零         |
| 咱得吃   | 被别人吃       | 都是被吃为什么不是被咱们吃 |

### 主动

#### 被拒绝

不确定对方是害羞还是真不喜欢咱,所以需要多次主动,直到我们被明确暗示拒绝,这个时候再不体面,可能就要被她帮咱体面.

#### 没被拒绝

一般来讲,同意的很少,都是不拒绝,所以没被拒绝就要发起猛烈攻击,我们的目标是快乐.

## 关于丑的照杀:

    如果你载在丑逼手里,这将会是你一生洗刷不掉的难以忘记的耻辱.
    如果你成功了你的快乐也不会太多,毕竟是丑逼.
    而且在这个过程中你不会是真心的,你只想拿她练手,所以潜意识里,自然而然的一些行为,动作,和脱口而出的语言不受你大脑控制,会伤害到她.
    所以这个策略不可取,伤天害理.
    就选漂亮的,练手也要选漂亮的.

## 关于外表:

    外表是第一印象,第一印象很重要.
