# 认知重构表格

## 使用说明

这是一个帮助你理性分析问题、调整负面情绪的工具表格。当你遇到困扰时，按照以下6个步骤填写，可以帮助你重新审视问题。

---

## 认知重构分析表

| 步骤 | 问题 | 我的回答 |
|------|------|----------|
| 1 | **具体事件/客观事实**<br>发生了什么？（只描述事实，不加评判） | |
| 2 | **我的感受和想法**<br>我有什么情绪？我在想什么？ | |
| 3 | **是否存在支持这种想法的证据**<br>有什么事实支持我的想法？ | |
| 4 | **这个证据是否有其他解释**<br>还有其他可能的解释吗？ | |
| 5 | **如果朋友遇到同样的事，我会怎么安慰他？**<br>我会对朋友说什么？ | |
| 6 | **现在我能控制/改变的是什么？**<br>我可以采取什么行动？ | |

---

## 填写示例

### 示例1：工作场景

| 步骤 | 问题 | 我的回答 |
|------|------|----------|
| 1 | **具体事件/客观事实** | 老板在会议上批评了我的方案，说需要重新修改 |
| 2 | **我的感受和想法** | 感到羞愧、沮丧。我觉得自己很失败，老板一定觉得我能力不行 |
| 3 | **是否存在支持这种想法的证据** | 方案确实被要求修改了，老板当众指出了问题 |
| 4 | **这个证据是否有其他解释** | 可能是方案本身需要完善，不代表我能力不行；老板可能只是就事论事；修改方案是工作常态 |
| 5 | **如果朋友遇到同样的事，我会怎么安慰他？** | 我会说：被要求修改很正常，这是改进的机会。老板指出问题说明他重视这个项目，你可以做得更好 |
| 6 | **现在我能控制/改变的是什么？** | 1. 仔细分析老板的反馈<br>2. 制定修改计划<br>3. 必要时请教同事<br>4. 按时提交改进版本 |

### 示例2：社交场景

| 步骤 | 问题 | 我的回答 |
|------|------|----------|
| 1 | **具体事件/客观事实** | 发微信给朋友，3小时了还没回复 |
| 2 | **我的感受和想法** | 感到被忽视、不安。我想：他是不是不想理我了？是不是我说错话了？ |
| 3 | **是否存在支持这种想法的证据** | 他确实没有回复我的消息 |
| 4 | **这个证据是否有其他解释** | 他可能在忙；手机没电；在开会；在开车；忘记回复；信号不好；有急事处理 |
| 5 | **如果朋友遇到同样的事，我会怎么安慰他？** | 我会说：别想太多，可能他在忙。如果真有问题，他会主动说的。给他点时间，不要过度解读 |
| 6 | **现在我能控制/改变的是什么？** | 1. 耐心等待回复<br>2. 做自己的事情转移注意力<br>3. 如果真的急可以打电话<br>4. 不要反复发消息 |

## 使用技巧

### 何时使用
- 感到焦虑、沮丧、愤怒时
- 陷入负面思维循环时
- 做重要决定前
- 与他人发生冲突后

### 填写要点

**步骤1 - 客观事实**
- 只写发生了什么，不加主观判断
- 避免使用"总是"、"从不"、"一定"等绝对词汇
- 像摄像机一样记录事实

**步骤2 - 感受和想法**
- 诚实面对自己的情绪
- 区分感受（情绪）和想法（认知）
- 允许自己有负面情绪

**步骤3 - 支持证据**
- 列出支持你想法的具体事实
- 区分事实和推测

**步骤4 - 其他解释**
- 尽可能多地列出其他可能性
- 跳出自己的视角看问题
- 考虑最好、最坏、最可能的情况

**步骤5 - 朋友视角**
- 用对待朋友的温柔对待自己
- 这一步通常能带来更理性的视角

**步骤6 - 可控因素**
- 专注于你能改变的事情
- 制定具体可行的行动计划
- 接受你无法控制的部分

## 认知扭曲类型参考

填写时注意识别这些常见的思维陷阱：

1. **非黑即白**：只看到极端，没有中间地带
2. **过度概括**：一次失败就认为"我总是失败"
3. **心理过滤**：只关注负面，忽略正面
4. **读心术**：认为自己知道别人在想什么
5. **预言家**：认为自己能预测未来（通常是坏结果）
6. **灾难化**：把事情想象得很糟糕
7. **情绪化推理**：因为感觉不好，就认为事情很糟
8. **应该思维**：过多使用"应该"、"必须"
9. **贴标签**：给自己或他人贴负面标签
10. **个人化**：把不相关的事情归咎于自己
